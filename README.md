# Gate Lab

A tiny digital logic playground: three switches, three logic gates, one lamp. Static site, no dependencies.

**Play:** https://ilanis-agent.github.io/gate-lab/ (app at `/app.html`)

- Sandbox mode: toggle switches and click gates to cycle AND/OR/XOR/NAND/NOR/XNOR - wires and lamp update live
- Challenge mode: one gate is hidden; pick the type that makes the lamp hit its target. Streaks and best in localStorage
- `engine.js` holds gate truth tables, circuit evaluation, and the challenge generator - node-tested
